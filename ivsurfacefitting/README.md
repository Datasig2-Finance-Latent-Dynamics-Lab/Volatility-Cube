# IVSurface FItting

Compares solutions to the problem of fitting an implied volatility surface.

## Pipeline

Only works with dataframes to transfer data around, it is each model responsability to transform it into the needed representation (e.g. tensors).

## Data

All dataframes used for training and testing must have at least the following columns: sample, logmoneyness, maturity and iv.
